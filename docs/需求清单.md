# 需求清单与检查标准

| 编号 | 需求 | 检查标准 | 版本 |
| --- | --- | --- | --- |
| 1 | 注册登录 | 用户名 3—20 位字母数字下划线；密码 ≥6 位且加盐存储；未登录访问发布页跳登录 | v1.0 |
| 2 | 发布商品 | 价格必须 >0 且 ≤100000；分类、成色必选；图片限 png/jpg/webp，成功后生成缩略图 | v1.0 |
| 3 | 分类浏览与详情 | 可按分类、成色单独或叠加筛选；详情页展示原图、描述、状态；待审核商品不对他人可见 | v1.0 |
| 4 | 搜索与排序 | 关键词匹配标题、描述、分类、成色；价格升降序正确；游标分页不重不漏 | v1.0 |
| 5 | 收藏 | 可收藏/取消收藏；我的收藏只列自己收藏的商品 | v2.0 |
| 6 | 留言 | 留言 1—300 字；只有发布者能回复；回复挂在原留言下 | v2.0 |
| 7 | 订单状态 | 待确认→已确认→已完成/已取消；非法跳转被拦截并提示；完成订单商品标记已售出 | v2.0 |
| 8 | 后台审核 | 仅管理员可进；通过后前台可见；驳回必须填原因；可下架商品 | v2.0 |

## 版本二新增的成色筛选（修改单）

版本一演示时教师指出只按分类找商品仍偏慢，成色是校园二手交易最常用的判断条件。于是需求 3 的分类筛选由一级改为「分类 + 成色」两维组合，需求 4 的搜索同步匹配分类与成色，约增加 2 人日，不改动版本一已交付的接口与页面结构。
